# P1-需求文档：智融数据问答平台

## 一、需求背景

### 1.1 现状分析

当前企业数据分析场景存在以下问题：

1. **数据分析门槛高**：业务人员需要掌握 SQL 等技术技能才能进行数据查询，技术团队承担大量临时取数需求
2. **响应效率低下**：从提出数据需求到获得结果，通常需要数小时至数天，影响业务决策时效性
3. **知识沉淀不足**：业务口径、查询案例缺乏系统化管理，相同问题反复沟通
4. **报告生成耗时**：分析报告依赖人工撰写，从数据收集到报告输出周期长

### 1.2 问题陈述

上述问题导致以下业务影响：

- 业务人员数据自主获取能力不足，过度依赖技术团队
- 数据分析周期长，错失业务决策窗口期
- 知识资产分散，难以形成标准化分析能力
- 报告类场景人工成本高，输出质量参差不齐

### 1.3 目标概述

构建智融数据问答平台，实现以下目标：

1. **降低数据使用门槛**：通过自然语言交互，让业务人员无需技术背景即可完成数据查询
2. **提升分析效率**：将数据需求响应时间从小时级缩短至分钟级
3. **沉淀业务知识**：建立结构化的业务知识库和案例库，支持智能召回与复用
4. **自动化报告生成**：基于主题、数据源和大纲，AI 辅助生成分析报告

### 3.2 功能详细说明

#### 3.2.1 智能数据问答模块

**核心流程：** 提问 → 问题拆解（可选）→ 执行查询 → 结果展示 → 图表生成（可选）→ 反馈收集

**关键特性：**
1. **自然语言理解**：支持中文自然语言查询，自动识别查询意图和关键实体
2. **多轮对话**：支持上下文关联的多轮问答，历史对话自动带入
3. **复杂问题拆解**：对于复杂查询，系统自动拆分为多个子问题，用户可确认和调整
4. **结果可视化**：支持一键生成图表，辅助理解查询结果
5. **反馈闭环**：支持正向/负向反馈收集，用于持续优化模型

#### 3.2.2 智能编排模块

**核心流程：** 需求输入 → 智能解析 → 编排展示 → 编辑调整 → 执行验证

**关键特性：**
1. **自然语言生成流程**：通过自然语言描述自动生成算子编排流程
2. **可视化编排**：支持对生成的流程进行查看、编辑和调整
3. **执行验证**：支持直接执行编排流程，验证业务逻辑正确性

#### 3.2.3 AI报告生成模块

**核心流程：** 主题配置 → 数据源选择 → 大纲生成 → 大纲调整 → 报告生成 → 正文编辑

**关键特性：**
1. **结构化大纲**：基于主题和数据源自动生成报告大纲
2. **灵活编辑**：支持章节/小节的增删改和拖拽排序
3. **富文本编辑**：提供完整的富文本工具栏，支持格式化排版
4. **AI辅助生成**：基于大纲自动生成报告正文内容

#### 3.2.4 后台管理模块

**数据源管理：**
- 支持多种数据源类型（MySQL、PostgreSQL、TeleDB、DM、本地文件）
- 三步配置流程：连接配置 → 表选择 → 字段元数据
- 支持语义检索配置和多表关联管理

**知识管理：**
- 业务知识：管理概念口径、业务释义类知识
- 案例库：管理问答案例和算子编排案例
- 支持向量同步，实现智能召回

**服务监控：**
- 核心指标统计（用户数、对话数、问答数、报告数）
- 使用趋势分析
- 活跃用户排行

**用户管理：**
- 账号增删改查
- 角色权限控制（普通用户/管理员）
- 启停用状态管理
