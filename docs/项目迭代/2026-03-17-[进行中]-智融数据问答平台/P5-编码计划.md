# P5-编码计划

> **For Claude:** REQUIRED SUB-SKILL: Use ideal-dev-exec to implement this plan task-by-task.

**Goal:** 构建智融数据问答平台，实现自然语言数据查询、智能编排、AI报告生成等核心功能。

**Architecture:** Next.js 14 全栈架构，使用 App Router + API Routes，Prisma ORM + MySQL 数据库，AI 能力通过第三方接口调用。

**Tech Stack:** Next.js 14 / React 18 / shadcn/ui / Tailwind CSS / Zustand / Prisma / MySQL / NextAuth.js
