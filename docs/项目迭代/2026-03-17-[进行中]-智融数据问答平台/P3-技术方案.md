# P3-技术方案：智融数据问答平台

## 一、方案概述

### 1.1 设计目标

基于 P1-需求文档，本技术方案旨在构建一个**企业级智能数据问答平台**，实现以下核心目标：

1. **自然语言数据查询**：用户通过自然语言完成数据查询，无需掌握 SQL
2. **智能编排能力**：支持通过自然语言生成和执行数据处理流程
3. **AI 报告生成**：基于主题和大纲自动生成分析报告
4. **统一知识管理**：沉淀业务知识和查询案例，支持智能召回
5. **企业级管理**：提供完整的后台管理能力

### 1.2 系统边界

| 范围 | 职责 | 说明 |
|------|------|------|
| **全栈应用** | ✅ 自研 | Next.js 14 全栈开发框架 |
| **API 层** | ✅ 自研 | Next.js API Routes + Server Actions |
| **AI 能力** | ❌ 第三方提供 | 由 AI 团队独立提供，本系统调用 |
| **数据存储** | ✅ 自研 | MySQL 业务数据库 |

### 1.3 核心设计原则

| 原则 | 说明 |
|------|------|
| 全栈统一 | Next.js 前后端统一技术栈，降低复杂度 |
| UI 一致性 | 统一采用 shadcn/ui 设计规范，水墨淡出风格 |
| 流式优先 | AI 交互采用 SSE 流式输出，打字机效果展示 |
| 接口解耦 | AI 能力通过接口调用，降低系统耦合度 |
| 安全合规 | 数据脱敏、权限控制、操作审计内置设计 |

### 3.3 流式输出与打字机效果

**SSE 流式处理 Hook：**

```typescript
// hooks/use-stream.ts
import { useEffect, useState, useCallback } from 'react';

interface StreamOptions {
  onChunk: (chunk: string) => void;
  onComplete: () => void;
  onError: (error: Error) => void;
}

export function useStream() {
  const [isStreaming, setIsStreaming] = useState(false);

  const startStream = useCallback(async (url: string, options: StreamOptions) => {
    setIsStreaming(true);
    try {
      const response = await fetch(url, { method: 'POST' });
      const reader = response.body?.getReader();
      const decoder = new TextDecoder();

      while (reader) {
        const { done, value } = await reader.read();
        if (done) break;
        const chunk = decoder.decode(value);
        options.onChunk(chunk);
      }
      options.onComplete();
    } catch (error) {
      options.onError(error as Error);
    } finally {
      setIsStreaming(false);
    }
  }, []);

  return { isStreaming, startStream };
}
```

**打字机效果组件：**

```typescript
// components/shared/stream-output.tsx
'use client';

import { useEffect, useState, useRef } from 'react';
import { cn } from '@/lib/utils';

interface StreamOutputProps {
  content: string;
  speed?: number;  // 打字速度 (ms/字符)
  className?: string;
  isStreaming?: boolean;
}

export function StreamOutput({
  content,
  speed = 30,
  className,
  isStreaming = false
}: StreamOutputProps) {
  const [displayedContent, setDisplayedContent] = useState('');
  const cursorRef = useRef<HTMLSpanElement>(null);

  useEffect(() => {
    if (!isStreaming) {
      setDisplayedContent(content);
      return;
    }

    let index = 0;
    const timer = setInterval(() => {
      if (index < content.length) {
        setDisplayedContent(content.slice(0, index + 1));
        index++;
      } else {
        clearInterval(timer);
      }
    }, speed);

    return () => clearInterval(timer);
  }, [content, isStreaming, speed]);

  return (
    <div className={cn('font-mono whitespace-pre-wrap', className)}>
      {displayedContent}
      {isStreaming && (
        <span
          ref={cursorRef}
          className="inline-block w-2 h-4 bg-ink-600 animate-pulse ml-0.5"
        />
      )}
    </div>
  );
}
```

### 4.3 WebSocket 问答封装

```typescript
// hooks/use-chat-websocket.ts
import { useEffect, useRef, useState, useCallback } from 'react';

interface ChatMessage {
  type: 'message' | 'case_data' | 'error' | 'done';
  content?: string;
  data?: unknown;
}

export function useChatWebSocket(url: string) {
  const wsRef = useRef<WebSocket | null>(null);
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [isConnected, setIsConnected] = useState(false);

  const connect = useCallback(() => {
    wsRef.current = new WebSocket(url);

    wsRef.current.onopen = () => setIsConnected(true);
    wsRef.current.onclose = () => setIsConnected(false);

    wsRef.current.onmessage = (event) => {
      const message: ChatMessage = JSON.parse(event.data);
      setMessages(prev => [...prev, message]);
    };
  }, [url]);

  const send = useCallback((data: unknown) => {
    if (wsRef.current?.readyState === WebSocket.OPEN) {
      wsRef.current.send(JSON.stringify(data));
    }
  }, []);

  const disconnect = useCallback(() => {
    wsRef.current?.close();
  }, []);

  return { messages, isConnected, connect, send, disconnect };
}
```

### 7.2 API Route 示例

```typescript
// src/app/api/chat/sessions/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { getServerSession } from 'next-auth';
import { prisma } from '@/lib/prisma';
import { authOptions } from '@/lib/auth';

// GET /api/chat/sessions - 获取会话列表
export async function GET(request: NextRequest) {
  try {
    const session = await getServerSession(authOptions);
    if (!session?.user?.id) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }

    const sessions = await prisma.session.findMany({
      where: { userId: session.user.id },
      orderBy: { updatedAt: 'desc' },
      include: {
        messages: {
          orderBy: { createdAt: 'desc' },
          take: 1,
        },
      },
    });

    return NextResponse.json({ data: sessions });
  } catch (error) {
    console.error('Get sessions error:', error);
    return NextResponse.json(
      { error: 'Internal server error' },
      { status: 500 }
    );
  }
}

// POST /api/chat/sessions - 创建会话
export async function POST(request: NextRequest) {
  try {
    const session = await getServerSession(authOptions);
    if (!session?.user?.id) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }

    const body = await request.json();
    const { title, description } = body;

    const newSession = await prisma.session.create({
      data: {
        userId: session.user.id,
        title: title || '新对话',
        description,
      },
    });

    return NextResponse.json({ data: newSession }, { status: 201 });
  } catch (error) {
    console.error('Create session error:', error);
    return NextResponse.json(
      { error: 'Internal server error' },
      { status: 500 }
    );
  }
}
```

### 8.2 AI 接口降级策略

```typescript
// lib/ai/fallback.ts
export async function withFallback<T>(
  primary: () => Promise<T>,
  fallback: () => T,
  options: { retries?: number; delay?: number } = {}
): Promise<T> {
  const { retries = 3, delay = 1000 } = options;

  for (let i = 0; i < retries; i++) {
    try {
      return await primary();
    } catch (error) {
      if (i === retries - 1) {
        console.error('AI 接口调用失败，使用降级方案');
        return fallback();
      }
      await new Promise(resolve => setTimeout(resolve, delay * (i + 1)));
    }
  }

  return fallback();
}
```
