# Story 007: AI报告模块

## 上下文

### 需求来源
> 来源：P1-需求文档.md#3.1.1 前台功能 - AI报告生成

支持围绕主题、数据源和大纲进行报告生成与编辑：
- 主题配置 → 数据源选择 → 大纲生成 → 内容生成 → 富文本编辑

### 技术方案
> 来源：P3-技术方案.md

富文本编辑器：TipTap/Lexical
AI 接口：
- POST /api/reports/{id}/outline SSE 流式
- POST /api/reports/{id}/generate SSE 流式
