# Story 002: 用户认证模块

## 上下文

### 需求来源
> 来源：P1-需求文档.md#3.1.2 后台功能

用户管理模块，支持账号增删改查、角色权限控制（普通用户/管理员）、启停用状态管理。

### 技术方案
> 来源：P3-技术方案.md v2.0#六、数据模型

使用 **NextAuth.js** 实现认证，用户数据模型：
- `User`: id, email, username, password, nickname, avatar, role, status

### 相关代码

依赖模块：
- `src/lib/prisma.ts` - Prisma 客户端（Story 001）
- `prisma/schema.prisma` - 数据模型（Story 001）
