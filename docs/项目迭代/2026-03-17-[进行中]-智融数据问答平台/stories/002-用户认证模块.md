# Story 002: 用户认证模块

## 上下文

### 需求来源
> 来源：P1-需求文档.md#3.1.2 后台功能

用户管理模块，支持账号增删改查、角色权限控制（普通用户/管理员）、启停用状态管理。

### 技术方案
> 来源：P3-技术方案.md#六、数据模型

使用 JWT + Passport 实现认证，用户数据模型包含：
- id, username, passwordHash, name
- department, role, isActive

### 相关代码

已完成的依赖模块：
- `apps/server/prisma/schema.prisma` - Prisma 配置（Story 001）
- `apps/web/src/app/layout.tsx` - 根布局（Story 001）
