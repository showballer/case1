# Story 006: 智能编排模块

## 上下文

### 需求来源
> 来源：P1-需求文档.md#3.1.1 前台功能 - 智能编排

支持通过自然语言生成和执行数据处理流程：
- 需求输入 → 流程解析 → 算子生成 → 算子编排 → 流程执行

### 技术方案
> 来源：P3-技术方案.md v2.0

使用 React Flow 实现可视化编排，AI 接口：
- POST /api/codeact/sessions/{id}/analyze SSE 流式
- POST /api/workflows/node/execute SSE 流式

### 相关代码

已完成的依赖模块：
- `src/app/api/datasources/*` - 数据源 API（Story 003）
- `src/lib/ai/client.ts` - AI 客户端（Story 004）
