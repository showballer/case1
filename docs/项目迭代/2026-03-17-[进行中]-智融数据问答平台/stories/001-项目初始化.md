# Story 001: 项目初始化与环境搭建

## 上下文

### 需求来源
> 来源：P1-需求文档.md#一、需求背景

构建企业级智能数据问答平台，需要先搭建项目基础框架。

### 技术方案
> 来源：P3-技术方案.md v2.0#二、系统架构

采用 **Next.js 14 全栈架构**，使用 App Router + API Routes：
- 前端：React 18 + shadcn/ui + Tailwind CSS
- API：Next.js API Routes
- 数据库：Prisma ORM + MySQL 8.0
- 认证：NextAuth.js

### 目录结构

```
zhirong-platform/
├── src/
│   ├── app/                      # App Router
│   │   ├── (auth)/               # 认证布局
│   │   ├── (main)/               # 主布局
│   │   └── api/                  # API Routes
│   ├── components/               # 组件
│   │   ├── ui/                   # shadcn/ui
│   │   ├── layout/               # 布局组件
│   │   └── shared/               # 共享组件
│   ├── hooks/                    # 自定义 Hooks
│   ├── lib/                      # 工具库
│   │   ├── prisma.ts
│   │   ├── auth.ts
│   │   ├── utils.ts
│   │   └── response.ts
│   ├── stores/                   # Zustand 状态
│   ├── types/                    # 类型定义
│   └── styles/                   # 样式
├── prisma/
│   ├── schema.prisma
│   └── seed.ts
├── public/
├── .env.example
├── next.config.js
├── tailwind.config.js
├── tsconfig.json
└── package.json
```
