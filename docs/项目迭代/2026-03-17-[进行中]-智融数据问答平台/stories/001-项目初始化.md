# Story 001: 项目初始化与环境搭建

## 上下文

### 需求来源
> 来源：P1-需求文档.md#一、需求背景

构建企业级智能数据问答平台，需要先搭建项目基础框架。

### 技术方案
> 来源：P3-技术方案.md#二、系统架构

采用 Monorepo 架构，使用 Turborepo 管理多包项目：
- `apps/web`: Next.js 14 前端应用
- `apps/server`: NestJS 后端应用
- `packages/types`: 共享类型定义

### 目录结构

```
zhirong-platform/
├── apps/
│   ├── web/                      # Next.js 前端
│   └── server/                   # NestJS 后端
├── packages/
│   └── types/                    # 共享类型
├── turbo.json
└── package.json
```
